# Антон: хранение тестовых данных и схема API

## Текущий пилот

Интерфейс — HTML, CSS и JavaScript. При запуске браузер создаёт локальную IndexedDB `anton-synthetic-pilot` с хранилищами:

- `users` — демонстрационные аккаунты и фиктивные роли;
- `referrals` — анкеты, состояния, предложения и история тестовых заявок;
- `audit` — локальные события для просмотра сценария;
- `meta` — отметка первичной загрузки примеров.

После перезагрузки данные остаются в текущем профиле браузера. Другая машина или пользователь их не увидит. Ни одно поле не отправляется на сервер. Реальные данные в IndexedDB вводить запрещено: браузерное разграничение ролей можно обойти.

## Реляционная схема для отдельного API-пилота

Файл [database/pilot-schema.sql](database/pilot-schema.sql) описывает будущую тестовую PostgreSQL-схему: организации, тестовые аккаунты, заявки, предложения, образцы вложений и события. Схема предназначена только для вымышленных записей и сама по себе не является системой защиты, эксплуатационной миграцией или разрешением на реальные данные.

## Как соединять сайт с базой

```text
HTML / JavaScript в браузере
             │ HTTPS: JSON API
             ▼
      Сервер приложения
             │ закрытое подключение
             ▼
      Тестовая PostgreSQL
```

Браузер не получает строку подключения, пароль БД или ключи. API проверяет сессию, роль, принадлежность заявки и допустимость перехода статуса на каждом запросе. Врач амбулатории получает только собственные заявки; стационар — опубликованные тестовые заявки; пациентский код связан с одной заявкой; администратор работает с тестовым контуром.

Для будущего тестового API можно использовать Node.js и PostgreSQL. Переменная подключения хранится только в серверной конфигурации. Доступ к PostgreSQL извне закрыт. Вложения в серверном пилоте — только заранее подготовленные фиктивные файлы или ключи на образцы; загрузка произвольных файлов в текущем демо выключена.

Пример вызова интерфейсом:

```js
const response = await fetch('/api/referrals?scope=mine', {
  credentials: 'include',
  headers: { Accept: 'application/json' }
});
if (!response.ok) throw new Error('Не удалось загрузить заявки');
const referrals = await response.json();
```

Пример серверного чтения PostgreSQL:

```js
const result = await pool.query(
  'SELECT id, status, procedure_text FROM demo_referrals WHERE created_by = $1 ORDER BY created_at DESC',
  [authenticatedUser.id]
);
```

## Границы пилота

Прототип проверяет только пользовательские Use Case и работу интерфейса на вымышленных записях. Он не отправляет реальные приглашения, не подтверждает клиническую пригодность и не резервирует места. GitHub Pages оставляется стендом показа фиктивных данных.
