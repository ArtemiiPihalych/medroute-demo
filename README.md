# Антон — демоверсия сервиса плановой госпитализации

Интерактивный прототип для обсуждения координации заявок между первичным звеном и стационарами Челябинской области.

> Все пациенты, клиники, цены и предложения вымышлены. Не вводите реальные персональные или медицинские данные. Это прототип интерфейса, а не медицинская информационная система.

## Сценарии

- **Врач стационара:** общий реестр, поиск и фильтры, просмотр заявки, подбор учреждения, создание предложения и подтверждение учебной госпитализации.
- **Врач амбулатории:** создание заявки и просмотр только своего демонстрационного списка.
- **Пациент:** экран отслеживания одной вымышленной заявки.
- **Администратор:** общий реестр для демонстрации; управление учётными записями пока не реализовано.

Переключайте роли в правом верхнем углу. Это переключатель сценария, а не авторизация или проверка безопасности.

В реестре есть 12 пробных заявок, 6 демонстрационных клиник и 6 профилей помощи. Поиск и подбор работают по вмешательству, оплате и готовности ехать в другой город. Заявки, предложения и статусы меняются только в памяти текущей вкладки. Перезагрузка возвращает исходные примеры.

## Запуск

Нужен Node.js 18 или новее, внешних зависимостей для сайта нет.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Статические файлы находятся в `dist/`.

```sh
npm run check
```

GitHub Actions публикует `dist/` на GitHub Pages после отправки изменений в ветку `main`.

## Что проверить с врачами

1. В роли врача амбулатории создайте заявку и убедитесь, что отображаются только «Мои заявки».
2. Переключитесь на врача стационара, откройте заявку Д-1042 и предложите подходящий вариант.
3. Проверьте, что заявка перешла на согласование, а затем подтвердите учебный приём.
4. Откройте роль пациента и обсудите экран отслеживания статуса.
5. Обсудите, какие этапы, поля и полномочия нужно изменить до разработки полноценной системы.

## Ограничения

В демоверсии нет серверной базы, настоящей авторизации, реального разграничения доступа, согласий, уведомлений, загрузки документов, интеграций и общей синхронизации между пользователями. Все записи существуют только в браузере. Совпадение по фильтрам не является медицинской рекомендацией; возможность госпитализации оценивает врач.

Перед использованием с реальными пациентами отдельно проектируются инфраструктура, правовые основания и договоры обработки данных, учётные записи, аудит и защита файлов. GitHub Pages используется только для публичного показа синтетического прототипа.

## Структура

- `dist/index.html` — интерфейс и формы.
- `dist/style.css` — оформление и адаптивность.
- `dist/app.js` — вымышленные данные и демонстрационные сценарии.
- `server.mjs` — локальный сервер для просмотра.
- `check.mjs` — проверка синтаксиса и файлов интерфейса.
