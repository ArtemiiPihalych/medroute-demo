# МедМаршрут

Интерактивный прототип координации плановых госпитализаций в Челябинской области: реестр пациентов, предложения стационаров и согласование приёма по ОМС или платно.

**Это демонстрация, не медицинская информационная система. Все пациенты, клиники, цены и предложения вымышлены. Не вводите реальные персональные или медицинские данные.**

## Возможности

- 12 исходных заявок, 6 демонстрационных клиник, 5 профилей помощи.
- Поиск по номеру, городу, диагнозу или вмешательству; фильтры по городу, профилю, оплате и статусу.
- Карточка пациента с предпочтениями, готовностью обследований и историей действий.
- Подбор предложений по виду вмешательства, оплате и готовности ехать в другой город.
- Создание предложения, возврат к подбору и подтверждение учебной госпитализации.
- Создание пробной заявки из ограниченного набора полей без ФИО, телефонов и документов.
- Адаптивный интерфейс, поддержка клавиатуры, диалоги и состояния пустого поиска.

Данные находятся только в памяти текущей вкладки. Перезагрузка страницы восстанавливает исходные примеры. Между браузерами и пользователями изменения не синхронизируются. Даты относятся к учебному сценарию октября 2026 года. Подтверждённые в демо госпитализации уменьшают число свободных мест; предложения не резервируют места.

## Запуск

Нужен Node.js 18 или новее, внешних зависимостей для работы сайта нет.

```sh
npm start
```

Открыть адрес http://127.0.0.1:4173. Статические файлы находятся в `dist/`. Для GitHub Pages их публикует workflow `.github/workflows/pages.yml`.

```sh
npm run check
```

## Что проверить с врачами

1. Открыть заявку Д-1042 и предложить стационар по ОМС.
2. Подтвердить выбор пациента и приём в учебном сценарии.
3. Посмотреть обновлённый маршрут в разделе «Госпитализации».
4. Создать заявку и проверить подбор по вмешательству, оплате и географии.
5. Обсудить, каких данных и действий не хватает реальному координатору.

## Ограничения

Нет серверной базы, авторизации, разграничения доступа, настоящих согласий, уведомлений, интеграции с медицинскими системами и хранения документов. Отображаемый демо-координатор не является защищённой учётной записью. Совпадение фильтров не является медицинской рекомендацией. Действия не меняют реальные очереди и не создают направления.

Для реальной эксплуатации необходим отдельный проект защищённой инфраструктуры в РФ, юридическая модель обработки данных, договоры с медорганизациями, учётные записи и аудит, проверка медицинских процессов и интеграций. GitHub Pages предназначен здесь только для показа вымышленного прототипа.

## Структура

- `dist/index.html` — разметка и формы.
- `dist/style.css` — оформление и адаптивность.
- `dist/app.js` — синтетические данные и взаимодействия.
- `server.mjs` — небольшой сервер для локального просмотра.
- `check.mjs` — проверка синтаксиса и наличия статических файлов.

При поддержке браузером WebMCP доступен необязательный инструмент `read_demo_referrals`, который только читает демонстрационные заявки. Работа интерфейса от него не зависит.
